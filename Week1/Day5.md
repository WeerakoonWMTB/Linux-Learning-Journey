# Day 5 - Users, Groups and sudo

## Objective

Learn how Linux manages users, groups and administrative privileges.

## Commands Learned

whoami

id

groups

sudo -l

## Concepts Learned

### User

A Linux account used to access the system.

### UID

Unique User ID assigned to each user.

### Group

A collection of users used for permission management.

### sudo

Allows a user to execute commands with administrative privileges.

### root

The superuser account with full control over the Linux system.

## Commands Practiced

whoami

id

groups

sudo -l

## Key Learning

- Linux manages access using users and groups.
- The sudo group provides administrative privileges.
- Root is the most powerful user in Linux.
