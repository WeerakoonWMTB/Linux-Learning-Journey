# Day 1 - Ubuntu Installation & Basic Commands

## Objective

Set up Ubuntu Linux and learn basic terminal navigation commands.

## Tasks Completed

- Installed Ubuntu 24.04 LTS on VMware
- Completed initial system setup
- Opened and used the Linux Terminal

## Commands Learned

### pwd
Displays the current working directory.

### ls
Lists files and directories.

### mkdir
Creates a new directory.

### cd
Changes the current directory.

### cd ..
Moves one directory back.

### touch
Creates a new empty file.

### rm
Removes a file.

### rm -r
Removes a directory recursively.

## What I Learned

- Linux uses a hierarchical file system.
- Everything starts from the root directory (/).
- Terminal commands are essential for Linux administration.
