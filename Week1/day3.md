## Commands Learned

### pwd

Displays the current working directory.

Example:

pwd

### ls

Lists files and directories.

Example:

ls

### cd

Changes the current directory.

Example:

cd /home

### cd ~

Moves to the current user's home directory.

Example:

cd ~

## Important Directories

### /

The root directory of Linux. Everything starts from here.

### /home

Stores user files and personal directories.

Example:

/home/tharindu-weerakoon

### /etc

Contains system configuration files.

Examples:

* /etc/hosts
* /etc/passwd

### /var

Stores logs and variable data.

Example:

/var/log

### /usr

Contains installed applications and user programs.

### /bin

Contains essential Linux commands and executable files.

## Comparison with Windows

Windows:

C:\Users\Username

Linux:

/home/username

Windows uses drive letters (C:, D:, E:).

Linux uses a single file system that starts from the root directory (/).

## What I Learned

* Linux uses a hierarchical file system structure.
* Everything starts from the root directory (/).
* Important system files are stored in directories such as /etc and /var.
* User files are stored in the /home directory.
* Linux does not use drive letters like Windows.
