# Day 7 - Git & GitHub

## Objective

Learn how to use Git and connect Linux with GitHub.

## Commands Learned

git clone
git status
git add
git commit
git push

## Practical Tasks

Installed Git

git --version

Configured Git User

git config --global user.name
git config --global user.email

Cloned Repository

git clone https://github.com/WeerakoonWMTB/Linux-Learning-Journey.git

Checked Repository Status

git status

## What I Learned

- Git is a version control system.
- GitHub hosts Git repositories online.
- Repositories can be cloned to Linux systems.
- Git is widely used in DevOps, Cloud and Software Development.
