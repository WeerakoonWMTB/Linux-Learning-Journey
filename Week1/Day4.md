# Day 4 - Linux Permissions

## Objective

Learn Linux file permissions and the chmod command.

## Commands Learned

ls -l

chmod 777

chmod 644

## Practical Tasks

Created:
- text1.txt

Tested Permissions:

### Default
-rw-rw-r--

### chmod 777
-rwxrwxrwx

### chmod 644
-rw-r--r--

## Key Learning

Linux permissions are divided into:
- Owner
- Group
- Others

Permission types:
- Read (r)
- Write (w)
- Execute (x)

## What I Learned

- Linux permissions use Read, Write and Execute.
- Permissions are assigned to Owner, Group and Others.
- chmod is used to change file permissions.
